# 读书观影卡片索引

这是一个 Codex Skill，用来把读书笔记、书摘、观影日记和影视笔记整理成类似豆瓣或微信读书的卡片索引，方便在 Obsidian 或 LLM Wiki 里视觉化查看。

它适合处理：

- 读书笔记、书摘、阅读感想
- 观影日记、影视笔记、剧集记录
- 需要按作品、摘录、主题、人物、场景归档的书影音材料
- 想做成卡片墙、作品索引、媒体索引的创作素材

## 核心原则

原始笔记是来源材料，不要搬空、覆盖或改写成总结页。

整理时应从原始笔记中抽取信息，生成新的卡片或索引，并保留回链。这样既能保留当时真实记录，也能得到更适合浏览和复盘的视觉化结构。

## 输出方向

这个 Skill 会引导 Codex 生成以下类型的卡片：

- 作品卡
- 摘录卡
- 主题卡
- 人物卡
- 场景卡
- 问题卡
- 创作素材卡
- 行动卡

实际生成时不需要全部创建，应该根据原始笔记内容选择最有价值的几类。

## 使用方式

在 Codex 中安装或引用这个 Skill 后，可以这样调用：

```text
Use $reading-media-cardizer 把这篇读书笔记整理成类似微信读书的卡片索引。
```

也可以用于观影日记：

```text
Use $reading-media-cardizer 把这篇观影记录整理成类似豆瓣的作品卡和场景卡。
```

## 文件

- `SKILL.md`：Skill 的主要说明和执行规则
- `agents/openai.yaml`：Codex 界面中显示的名称、简介和默认提示语
